Data Management

Backup & Restore

Save Your Data Before Switching Systems

localStorage only saves in your browser. To move data to another computer, Export first then Import on the new system.

How to Transfer Data
  1. System 1: Click Export Data → save the JSON file
  2. Copy the whole project folder + the JSON file to a USB/new system
  3. System 2: Open admin → click Import Data → select the JSON file
  4. Page reloads — all products, images, settings restored!
